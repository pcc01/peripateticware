# Contributors to Peripateticware

We're grateful to every person who contributes to Peripateticware. Whether it's code, documentation, design, or community support, every contribution makes Peripateticware better for educators and students.

This page celebrates everyone who has helped build Peripateticware. If you've contributed and aren't listed, please let us know!

---

## 🏆 How Recognition Works

Contributors are recognized based on their involvement:

- **🌱 Tier 1**: First-time contributors (1-3 contributions)
- **🌿 Tier 2**: Active contributors (4-10 contributions or significant work)
- **🌳 Tier 3**: Core contributors (10+ contributions or major features)
- **⭐ Tier 4**: Maintainers (merge permissions, RFC authors, project leadership)

Recognition includes:
- ✅ Public listing in CONTRIBUTORS.md
- ✅ Credit in every release you contributed to
- ✅ Speaking opportunities at community events
- ✅ Mentorship and skill development
- ✅ Career visibility and portfolio building
- ✅ Advisory input on project decisions (Tier 2+)

## 💡 How to Become a Contributor

### Getting Started
1. **Read** [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines
2. **Look for** [good-first-issue](https://github.com/teacher-tools/repo/issues?q=is%3Aissue+is%3Aopen+label%3Agood-first-issue) labels
3. **Ask questions** in [GitHub Discussions](https://github.com/teacher-tools/discussions)
4. **Submit** your first pull request

### Areas We Need Help With

#### Code
- **Backend** (Python/FastAPI): API improvements, performance, features
- **Frontend** (React): UI enhancements, accessibility, features
- **Mobile** (React Native): iOS/Android testing and optimization
- **Docs**: API documentation, tutorials, guides

#### Non-Code
- **Documentation**: README improvements, API docs, guides
- **Design**: UI/UX improvements, accessibility enhancements
- **Community**: Issue triage, answering questions, mentoring
- **Testing**: Bug reports, test coverage improvements
- **Content**: Blog posts, tutorials, case studies
