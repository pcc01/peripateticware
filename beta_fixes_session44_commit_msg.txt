instead of AIRouter().complete() - AIRouter.complete() has no

ai_router.py, independently re-confirmed by the Test Agent), and both
prompts need specific low temperatures (0.10/0.30) for reliable JSON
output. Trade-off: these two task types currently bypass the org-level
budget/ledger tracking other AI task types get - moot today since
Ollama is free, worth revisiting if Claude routing is wanted for these
later.
